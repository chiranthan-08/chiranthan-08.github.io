# Chiranthan Siddu K S — Professional Portfolio Website

An ultra-modern, responsive, and SEO-optimized portfolio website for **Chiranthan Siddu K S** (Information Science and Engineering | CIT Tumkur).

## 🌟 Highlights & Tech Architecture
- **Zero-Dependency Core**: HTML5, Vanilla CSS3 (Custom Design System with Glassmorphism & Cyber Theme), Modern Vanilla JavaScript (ES6+).
- **Interactive Features**: Dynamic typing hero, skill category filtering, animated stats counter, interactive project modals, high-res resume preview and download modal, direct email integration, and mobile drawer navigation.
- **Search Engine Discovery (SEO)**: Full Schema.org JSON-LD structured data, Open Graph social meta tags, `robots.txt`, and `sitemap.xml`.
- **100% Free Lifetime Hosting**: Ready to deploy on GitHub Pages, Vercel, or Netlify with zero hosting fees forever.

## 💻 Local Preview
To preview locally:
- Open `index.html` in any web browser, or
- Start a simple local server:
  ```bash
  # Python 3
  python -m http.server 8000
  # or Node.js (npx)
  npx serve .
  ```
  Then visit `http://localhost:8000`.
